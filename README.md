# Mobious

A high-performance utility optimized exclusively for Unix environments.

## System Requirements

* **Operating System:** Unix-based platforms (Linux, macOS, BSD)
* **Architecture:** x86_64 / ARM64
* **Shell:** Bash 4.0+ or Zsh

> [!NOTE]  
> This software utilizes native Unix system calls. Windows and non-POSIX environments are explicitly unsupported.
